# Brand Guidelines

## Brand name

**Balans in kwalietijd**

The website represents the independent practice **Balans in kwalietijd**, offering bedrijfsmaatschappelijk werk.

---

# Brand values

The visual identity should communicate:

* Trust
* Reliability
* Professionalism
* Calmness
* Personal attention
* Warmth

Avoid a corporate, sales-oriented, or overly clinical appearance.

# Color palette

## Primary

### Terracotta

```text
#C36A4B
```

Warm, human, approachable.

Used for:

* Primary buttons
* Links
* Small accents
* Highlights

---

### Deep Slate

```text
#2C3531
```

Professional and grounded.

Used for:

* Headlines
* Navigation
* Important UI elements

---

### Warm Sand

```text
#E0A96D
```

Soft supporting accent.

Used sparingly for:

* Background accents
* Dividers
* Cards
* Icons

---

### Cream

```text
#FAF6F0
```

Primary page background.

Provides warmth while maintaining excellent readability.

Most sections should use this color or a very similar neutral background.

---

### Charcoal Gray

```text
#1E222A
```

Body text and high-contrast content.

Should provide the primary reading color.

---

# Typography

Primary typeface:

**Montserrat**

Montserrat is used in the logo and should also be the primary heading typeface for the website.

A complementary body font may be selected later if readability benefits, but using Montserrat throughout the site is also acceptable.

---

# Photography

Primary portrait:

```text
assets/photos/headshot.jpeg
```

This image should be treated as a core trust-building element.

Recommendations:

* Display prominently in the hero section.
* Avoid heavy filters or overlays.
* Preserve natural colors.
* Prefer generous whitespace around the portrait.

---

# Design language

The website should feel:

* Calm
* Elegant
* Trustworthy
* Personal
* Modern
* Minimal

Avoid:

* Busy layouts
* Large gradients
* Stock photography
* Excessive animations
* Marketing-heavy visuals
* Loud colors

Whitespace is considered an important part of the visual identity.

---

# Accessibility

When using the color palette:

* Ensure sufficient contrast for all text.
* Never rely solely on color to communicate meaning.
* Buttons and links should remain clearly distinguishable.
* Test designs against WCAG AA contrast guidelines.
